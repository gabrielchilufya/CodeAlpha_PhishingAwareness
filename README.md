# CodeAlpha Phishing Awareness Training

An interactive web module that teaches people how to recognize and avoid phishing attacks.
Built for the **CodeAlpha Cyber Security Internship (Task 2)**.

**Live demo:** https://gabrielchilufya.github.io/CodeAlpha_PhishingAwareness/

## What it covers
- **Spot the phish:** an interactive fake email with 5 red flags to find
- **Social engineering tactics:** urgency, authority, fear, greed, trust, and other channels (smishing, vishing)
- **Real-world examples:** Target (2013), Ubiquiti (2015), Google Docs (2017), Twitter (2020)
- **Best practices:** a checklist for protecting yourself
- **Quiz:** 6 questions with instant feedback and a final score

## How to run
Open `index.html` in any web browser. No installation or dependencies needed.

## Tech
HTML, CSS, and vanilla JavaScript in a single file.
